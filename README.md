# 🇬🇳 RADIOS GUINÉE

Une application web moderne et intuitive pour écouter les principales stations de radio guinéennes en direct et suivre vos podcasts préférés.

## 🚀 Fonctionnalités en cours de développement
* **Écoute en direct :** Streaming audio haute qualité pour Espace FM, RTG, Sabari FM, et bien d'autres.
* **Recherche intelligente :** Filtrage des stations par nom ou par catégorie (Musique, Info, Généraliste).
* **Favoris :** Sauvegardez vos radios préférées pour y accéder en un clic.
* **Interface Sombre :** Un design élégant et optimisé pour le confort visuel sur mobile.

## 🛠️ Technologies
* HTML5 / CSS3 (Interface utilisateur)
* JavaScript (Logique de lecture audio - *À venir*)
